Wedding RSVP — Google Sheet layout
==================================

Row 1 headers (columns A–J):

  A: Timestamp
  B: Full name
  C: Attending             (values: yes / no — do not change spelling)
  D: Guest names           (blank when not attending)
  E: Guests numbers        (number; 0 when not attending)
  F: Recovery dinner       (yes / no / blank)
  G: Notes                 (dietary requirements; blank when not attending)
  H: Responses             (live total — formula below)
  I: Attendees             (live total — formula below)
  J: Rejections            (live total — formula below)

Dynamic totals (recommended)
----------------------------
Put these three formulas once in row 2 (cells H2, I2, J2). Leave A2:G2 empty
until the first RSVP arrives, or keep the formulas in H2:J2 on the same row
as your first guest — they will keep updating as new rows are added below.

  H2  =COUNTA(FILTER(B2:B, B2:B<>""))
  I2  =SUM(FILTER(E2:E, C2:C="yes"))
  J2  =COUNTIF(C2:C, "no")

These ranges (B2:B, C2:C, E2:E) grow with every new submission, so the totals
are always up to date — no need to copy formulas down.

What they mean:
  Responses   — number of RSVPs submitted (rows with a name)
  Attendees   — total people coming (sum of Guests numbers where Attending = yes)
  Rejections  — number of “no” replies

Optional: pin row 1 (View → Freeze → 1 row) so headers stay visible.

Timestamp column
----------------
New rows get a readable local time from the server, e.g.:
  Fri 23 Oct 2026, 16:30
(Argentina / Buenos Aires timezone, 24-hour clock)

It is saved as plain text, so Sheets shows it exactly like that and never turns
it into a date number. If old rows show numbers like 46318.68, select column A
and choose Format → Number → Date time to make them readable.

Older rows may still show ISO format (2026-10-21T…); you can leave them or
reformat manually. New submissions after redeploy use the friendly format.

Netlify
-------
  GOOGLE_SHEET_RANGE=Sheet1!A:G

Change Sheet1 if your tab name is different.
